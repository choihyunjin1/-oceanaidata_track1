## Why there is no valid ten-minute new axis

- A valid signature bank needs its type definitions, feature normalization, signature thresholds, event aggregation, and inner selection rule fixed before outer labels. Existing repositories already contain all five anomaly types, type heads, interval proposals, donor signatures, and event-ranker gates. Choosing a new subset or threshold now would be selection on repeatedly exposed Q2/Q3/Q4 surfaces.
- GI2 cannot be reconstructed from the official aggregate observation. Turning its two official rows into a historical rule would use Public feedback as row-level supervision and would not support a paired Q3/Q4 bootstrap.
- Remaining genuinely orthogonal work would require either a fresh chronological label block or a new deployable causal covariate. Neither can be created, validated twice, and independently QA'd in ten minutes.

## Stop decision

Do not create a v32i attempt lock, model, threshold, action mask, or materializer. Reopen only with a fresh labeled chronological block or a pre-existing frozen historical GI2-equivalent mask whose provenance predates Public feedback.
