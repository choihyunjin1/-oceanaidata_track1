2026 해양과학 AIx빅데이터 경진대회 데이터분석 대학부 참가팀입니다. 공고문과 참가자 전용 제출 안내를 확인했으나 외부 공개자료와 공개 사전학습 가중치의 허용 범위를 찾지 못하여, 모델 실험 전에 아래 사항을 서면으로 확인 부탁드립니다.

### 1. 외부 공개자료의 일반 허용 여부

학습기간보다 과거이고 공개 라이선스가 명확한 관측·재분석 자료를 사전학습, 특징 설계 또는 모델 학습에 사용하는 것이 허용됩니까?

- P1/P2 후보: KIOST ScienceWatch의 2023년 이전 수온·염분·수심 자료
- P3 후보: 2023년 이전 KMA 해양기상부이·파고부이, ERA5, NOAA WAVEWATCH III hindcast

허용된다면 다음 범위를 구분해 부탁드립니다.

1. 원자료를 대회 train과 직접 결합
2. 외부자료로 사전학습 후 대회 train으로 fine-tuning
3. 외부자료로 계절통계·정규화·규칙·임계값 산정
4. 물리 모델 또는 합성 시뮬레이션으로 만든 데이터 augmentation
5. 최종 제출에서 DOI·버전·라이선스·가공코드·원자료 포함 여부

### 2. 공개 사전학습 모델

MOMENT, Chronos 등 공개 시계열 foundation model의 가중치를 사용하거나 fine-tuning하는 것이 허용됩니까? 허용된다면 checkpoint 이름·버전·라이선스·사전학습 데이터 출처를 어떤 형식으로 공개해야 합니까?

### 3. 평가기간·가림기간과 겹치는 외부 값

저희 팀은 일반적인 외부자료 허용 여부와 무관하게 아래 자료는 정답 또는 익명시각 복원 위험 때문에 사용하지 않을 계획입니다.

- P1: 2024~2026 KORS/KHOA 원신호·실시간 값
- P2: 2025-09-01~10-31 S-ORS layer 2·3·4 수온·염분
- P3: 2025-07-04~2026-06-30 외부 관측·재분석·파랑모델 값을 test context와 대조하는 행위

위와 같은 직접 중첩자료의 대조·학습·특징 사용이 금지 대상이라는 이해가 맞는지 확인 부탁드립니다.

### 4. 라이선스가 불명확한 S-ORS 과거자료

ScienceWatch의 `S-ORS mooring observation data of temperature and salinity since 2015`(2015~2023, DOI 10.22808/DATA-2024-7)는 개별 공개 라이선스가 페이지에 표시되지 않습니다. 대회 측이 외부자료를 허용하더라도 KIOST의 별도 사용 허락 없이는 사용하지 않는 것이 맞는지 확인 부탁드립니다.

### 5. 재현 패키지

외부자료가 허용될 경우 원자료는 용량·재배포권 문제로 제출 zip에 넣지 않고, 다운로드 코드·공식 URL·DOI·버전·SHA256과 전처리 절차만 제출해도 되는지 확인 부탁드립니다. 운영진이 재현 시 동일 자료를 별도로 배치해야 한다면 권장 입력 구조도 알려주시면 감사하겠습니다.

답변을 받기 전까지 외부 관측값과 외부 사전학습 가중치는 모델·검증·임계값에 사용하지 않겠습니다. 답변 원문을 규정 기록으로 보존하고 그대로 준수하겠습니다.
