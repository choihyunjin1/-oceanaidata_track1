## Fixed structural hypothesis

The organizer README fixes ten-minute cadence and a minimum three-hour duration for non-spike noise. V60 therefore uses exactly 18 trailing rows within each station-layer exact-cadence segment. After station-layer prefix-only median/MAD normalization, it draws the endpoint chord, chooses the single internal point of maximum absolute chord deviation, and reports:

- endpoint-chord slope;
- maximum and signed breakpoint deviation;
- breakpoint location;
- two-segment residual RMS;
- two-segment path excess;
- signed turning angle;
- whether the deviation exceeds the fixed 0.25 prefix-scale tolerance.

The representation is causal and deterministic. It has no grid, adaptive range expansion, result-conditioned retuning, external data, pretrained weights, or prior prediction input. A scratch linear logistic add-only head uses the already frozen seeds, training schedule, threshold candidates, cross-quarter veto, and Q4 gate.

Repository-wide executable fingerprinting found no Ramer-Douglas-Peucker, maximum-deviation adaptive polyline split, or single-break line-simplification feature before this registration. The method is not:
