# P1 v33 prospective rejected-candidate auditability amendment

v32 showed that threshold and model hashes alone cannot support a later zero-fit false-negative audit. For every new axis after this amendment, the runner must seal label-blind Q2 ensemble scores and a fixed-budget add-only action mask for every pre-Q2 numeric threshold candidate before any Q2 target access. The same manifest records authenticated row positions, incumbent predictions, per-seed model/scaler hashes, threshold/count/share receipts, and bundle hashes.

This changes artifact preservation only. It does not open Q2 labels, alter v28, relax a gate, reselect a threshold, refit a model, promote a rejected candidate, or apply retroactively to v29/v30. A later audit still needs a new ID and explicit authorization, may open at most one target window with zero fits/refits, and can never rescue the original candidate.

Official/test/sample/submission/hidden reads, CSVs, and uploads remain zero.
