# 남은 범위

| 범위 | 상태 | 다음 판단 |
|---|---|---|
| 현재 진입 지침·스킬 | 완료 | 내용 변경/문제 범위 변경 때만 재독 |
| 반복 코드 검사 | 집중 테스트 통과 | 모델·데이터 QA와 분리, 새로운 의존성은 캐시 사용 범위 점검 |
| 역사적 Python 전체 삭제 | 미실시 | 참조·hash·재현 의존성을 증명하지 못한 삭제는 금지 |
| 설치된 타사 스킬·전역 설정 | 보존 | 구체적으로 제거할 대상을 정하기 전 일괄 제거 안 함 |
| 기존 최종 패키지 갱신 | 미실시 | 새 적격 모델 전체 재학습/재현 후 별도 수행 |
| Git commit/push | 미실시 | 현재 작업에는 새 승인 없음 |
