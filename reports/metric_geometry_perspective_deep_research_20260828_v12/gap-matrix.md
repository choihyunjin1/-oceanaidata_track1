# Evidence Gap Matrix

| 질문 | 현재 근거 | 남은 공백 | 다음 행동 |
|---|---|---|---|
| P2 alpha 0.50은 같은 scorer에서 개선하는가 | 공식 RMSE 0.431252로 개선, 사전등록 범위 안 | 해소 | alpha50을 포함해 다음 기하 재계산 |
| P2 개선이 최종 평가로 운반되는가 | 없음 | public/private 분할·최종 scorer | 운영진 규칙 확인, 후속 적응 최소화 |
| P1에서 어떤 변경 셀이 공식 이득을 냈는가 | 일부 통제 실험과 공식 F1 | 모든 후보의 공통 이견셀 원장 | champion 기준 셀 audit |
| P3에 독립적인 추가 정보가 있는가 | 현 wind/Hs² 축은 수렴 또는 악화 | 저상관 residual direction | 새 독립축이 없으면 제출 중지 |
| 하루 3회 모두 쓰는 것이 유리한가 | 적응 과적합 문헌은 반대 위험을 제시 | 대회 분할 상세 미공개 | 한 축 한 번 측정 원칙 유지 |
| 점수기하 사용의 규칙 적합성 | 일반 제출·점수 확인 기능은 공식 | 점수 재사용 상세 규정 없음 | 행별 라벨 추론 금지, 저차원 집계 분석만 유지 |
