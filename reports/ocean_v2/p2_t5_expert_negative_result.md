# P2 T5 전문가 — 동일 가설 재시도 금지 원장

정확한 3-seed 실험은 이미 종료되었다. **첫 seed의 개선이 배포 기준인 3-seed 평균에서는 재현되지 않았다.**

- 가을 intact: C 0.488284326 → conditional 0.489067844℃, Δ+0.000783517℃.
- 전체 intact: 0.859249914 → 0.860501412℃, Δ+0.001251499℃.
- 가을 지원완료 7/14일 outage: 0.772421618 → 0.803223321℃, Δ+0.030801703℃.
- 상태 `NO_INTERNAL_SUPPORT_FOR_CONDITIONAL`; 임계값·seed·epoch를 바꾸어 같은 가설을 자동 재개하지 않는다.

단일 수치 근거와 학습/QA/hash는 [기존 3-seed canonical 보고서](../p2_missingness_conditional_3seed_20260905_v3/report-source.md)에 있다. 이 파일은 참조용 색인이며 재실행·재판정 영수증이 아니다. 프로파일 copula 잔차 보정은 다른 가설이지만, 그것도 같은 기준·평가키에서 실제 비교해야 한다.
