## 5. 취약점·한계 레지스트리 (요약; 상세는 문제별 정찰 파일)

### P1
1. 검증 fold가 2025-04~12뿐 → test(2026-01~06, 5~6월 55%) 계절 미검증. 2. O/B OOF purge 7일 < centered 특징 지원 337h → 누출된 0.86. 3. test 세그먼트 단절이 train보다 3.4배(장기창 결측 18~32%), 모델은 "장기창 있음" 분포에서 학습. 4. G-ORS 2026 depth 전결측(미학습 조합), I-ORS L3 부재. 5. singleton spike 규칙 FP(83행 vs 기대 22). 6. e150은 300-epoch cosine의 중간 체크포인트(LR 미어닐링), 자체 확인 gate NO_GO였던 계열. 7. Public은 test의 ≈28~31% 행만 반영(S-ORS 변화가 관측되지 않음). 8. 손실 본체: offset/drift 장기 이벤트 내부 행(FN의 92.7%), 유형별 recall offset 0.65·drift 0.65.
### P2
1. 80% anchor가 LB 적합·재생성 불가. 2. comparator 비현실·action cap 포화. 3. baseline 정의 불일치(학습 외삽 vs 추론 clamp). 4. test 29.3% T5 결측(10/14~10/31 연속 17일, 강성층 T1−T6 7.8℃)인데 어떤 fold도 이 regime 없음. 5. hidden 행 실제 depth 99.3% 존재하나 미사용. 6. psal_1 test 유효율 56.6%(학습 ≥90%) 분포 이동. 7. DeepSets는 동시각 프로파일만(시간 문맥 없음). 8. 2024/2025 layer↔수심 불일치를 OAS는 layer 번호로 취급.
### P3
1. LB 적합 α(12h는 Public에서도 근거 없음). 2. 학습 anchor(hs≥1.5 전 시각 24,360) vs test(onset, 최초 교차 71%) 분포 불일치. 3. I/S-ORS 2024 기상 전무 → `wspd_valid_*=0`이 연도 프록시(25Q2 fold에서 persistence보다 악화). 4. I-ORS 2024-08~10 파랑 100% 결측(태풍기 공백). 5. multi GPU Plain 비결정, 단일 seed. 6. 라우터 학습/적용 불일치. 7. 181사례 검증면 60회 재사용. 8. ~60개 residual cycle이 부적격 KMA reference 위 10% ridge라 clean 계보에 무용.
### 프로세스
로컬→공식 방향 일치 1/5~6/14; 게이트가 초기엔 과도하게 엄격했다가 후반엔 우회; 08-29 이후 30여 건 프로브의 순증 +0.0007점; P1 구조 변경은 08-27 이후 시도되지 않음.

## 6. 문제별 검증 사실 (설계 근거)
- **P1**: 자연 연속 동일값 run 최대 4~5행 vs flatline ≥12행 → 하드 룰 가능. 주입은 temp 전용(psal/depth 불변): noise 내부 dT std 2.98 vs dS 0.033. offset은 대칭 점프쌍(|entry|,|exit|≥0.5℃ 96.9%, 부호 반대 96.9%), drift는 무음 진입+큰 이탈 점프(≥0.8℃ 96.4%). 이벤트는 세그먼트 경계 3행 이내 0건. 계열별 양성률 3.99~4.19% 균일. 자연 |dT| p99가 5~9월 S-ORS 중층에서 4~5℃ → FP 위험. test 간격 분위(분) 60/120/950/4140/19477.
- **P3**: test = 폭풍 onset(직전 3h 최소 hs<1.5 비율 0.77, 상승 85%, hs0 중앙 1.64). 정시(:00) 격자 greedy 78h 복제가 test 구성(first_cross 0.28 vs 0.30)과 정합. onset에서는 파고 모멘텀보다 **바람(wspd, 6h 변화)**이 정보. 바람-드롭아웃 증강 −0.011 m(측정). 선정-정합 재가중은 이득 없음(+0.005, SE 0.003). 로컬 a_L은 shrink(0.74~0.95) 선호하나 Public 실측은 반대 → 기본은 항등.
- **P2**: 2024-09/10 가상 가림: nominal 보간 0.971, 실제수심 보간 0.880, T1 복사 0.593, LGBM(y−T1, T5 마스크 증강) 0.563, 3목표 평균+envelope/PAVA 0.558. 2025-11/12(완전 혼합): T1 복사 0.068 vs GBM 0.28~0.37. 잔차 ACF 12h 0.55/24h 0.45(내부조석) → 시간 문맥 유효. 2025-10 후반 T5 부재·강성층은 어느 해에도 없는 regime.
