### 1. 2023년 이전 외부 공개 관측자료 사용

KIOST ScienceWatch에 공개된 아래 자료를 모델의 사전학습, 정상 계절성·정점·층별 기준선 추정, 피처 설계 또는 임계값 설정에 사용하는 것이 허용되는지 문의드립니다.

1. I-ORS mooring observation data of temperature and salinity since 2014
   - 기간: 2014~2023
   - 변수: 수온, 염분, 수심 및 품질관리 결과
   - 시간 간격: 10분
   - DOI: 10.22808/DATA-2024-6
   - 공개 페이지: https://sciwatch.kiost.ac.kr/handle/2020.kiost/46422
   - 페이지 표시 라이선스: CC BY 4.0

2. Ieodo Ocean Research Station observations from 2004 to 2023
   - 기간: 2004~2023
   - 수온: 5m, 21m, 38m의 1시간 품질관리 자료
   - DOI: 10.22808/DATA-2025-2
   - 공개 페이지: https://sciwatch.kiost.ac.kr/handle/2020.kiost/46771
   - 페이지 표시 라이선스: CC BY 4.0

허용된다면 다음 범위를 구분해 답변 부탁드립니다.

- 모델 학습 데이터로 직접 결합
- 정상 기준선 또는 계절 통계 산정
- 피처·규칙·임계값 설계
- 외부자료로 사전학습한 모델의 fine-tuning
- 본선 제출 시 DOI, 버전, 라이선스, 가공 절차 공개 형식

### 2. 대회 기간과 겹치는 원자료·실시간 자료

KORS/KHOA 포털에는 대회 train 기간인 2024~2025년 또는 test 기간인 2026년과 겹칠 수 있는 원자료·실시간 자료가 존재합니다.

저희는 이 자료가 합성 이상 주입 전 신호와 직접 대응할 가능성이 있어 정답 복원 또는 평가 누출 위험이 있다고 판단했습니다. 따라서 2024~2026년 외부 원자료, 실시간 관측, 같은 시점의 공개 미러는 사용하지 않을 계획입니다.

이와 같은 기간 중첩 원자료의 대조·학습·피처 사용이 금지 대상이라는 이해가 맞는지 확인 부탁드립니다.

### 3. 과거 S-ORS 자료의 권리 조건

ScienceWatch의 S-ORS 2015~2023 10분 CTD 자료 페이지는 품질관리 결과를 제공하지만 개별 공개 라이선스가 표시되지 않습니다.

- DOI: 10.22808/DATA-2024-7
- 페이지: https://sciwatch.kiost.ac.kr/handle/2020.kiost/46423

해당 자료는 KIOST의 별도 사용 허락과 대회 측 승인을 모두 받기 전에는 사용하지 않는 것이 맞는지 확인 부탁드립니다.

### 4. 미래 시점 또는 양방향 시간창

현재 공개 문제문은 완성된 train/test 시계열의 각 시점을 판정하도록 하며 online-only 제약을 명시하지 않습니다. 이에 참가팀 내부 승인 계획에서는 양방향 offline QC를 주력으로, causal QC를 실운영 비교용 ablation으로 분리해 검증하고 있습니다. 아래 질문은 offline 실험의 사전 허가를 요청한다기보다 최종 제출 범위와 공식 해석을 확인하기 위한 것입니다.

본 문제의 자동 품질관리가 다음 중 어느 방식으로 평가되는지 문의드립니다.

- 실시간 online/causal 판정: 현재 및 과거 관측만 사용
- 사후 offline 판정: centered rolling, 양방향 이웃, 미래 관측 사용 가능

centered rolling median, 양방향 차분, 미래 층간 동시성 같은 특징의 허용 여부를 명확히 알려주시면 감사하겠습니다.

### 5. 사전학습 모델·외부 라이브러리·앙상블

다음 항목의 허용 범위와 공개 의무를 문의드립니다.

- 공개 사전학습 시계열 모델
- 공개 Python 라이브러리와 change-point 패키지
- 여러 모델·규칙 기반 예측의 앙상블
- 생성형 AI를 이용한 코드 작성·디버깅
- 사용 모델, 라이브러리, 프롬프트의 제출·공개 형식

### 6. 하루 1회 제출 규칙

P1 제출 기회가 하루 1회인 것으로 안내받았습니다. 아래 운영 기준을 확인 부탁드립니다.

- 하루의 기준 시간대와 초기화 시각
- 형식 오류 또는 업로드 실패도 1회로 차감되는지
- 제출 취소·교체·재제출 가능 여부
- public/private 리더보드 분할과 최종 평가 방식

### 7. 최신 대회 UI와 초기 공고 PDF의 일정 불일치

2026-08-13에 확인한 최신 대회 UI는 문제 공개일을 2026-08-13, 제출 마감·최종 모델 지정일을 2026-09-07로 표시합니다. 반면 2026-07-24 게시된 KIMST 초기 공고 PDF는 대학부 온라인 해커톤을 2026-08-10~09-04, 코드·데이터셋 zip 마감을 2026-09-04 10:00 이전으로 안내합니다.

최신 UI를 현재 운영 기준으로 이해하고 있으나, 다음을 서면으로 확인 부탁드립니다.

- 최종 제출 마감일과 정확한 시각 및 기준 시간대
- 2026-09-07의 최종 모델 지정과 코드·데이터셋 zip 업로드가 같은 마감인지
- 초기 PDF의 2026-09-04 10:00 마감 문구는 폐기된 일정인지
- 본선 진출자 발표 이후 일정도 함께 변경되었는지

### 8. 예선 결과물의 코드·데이터셋 zip 범위

KIMST 초기 공고 PDF는 2026-09-04 10:00 이전에 코드·데이터셋 zip을 제출하고 코드·데이터 재현성을 검증한다고 명시합니다. 최신 UI는 제출 마감·최종 모델일을 2026-09-07로 표시하지만 패키지 범위는 명확하지 않습니다. 한편 P1 배포 README는 배포자료 재배포를 금지합니다.

다음 중 어떤 방식으로 제출해야 하는지 확인 부탁드립니다.

1. 원본 CSV/ZIP을 제외하고 코드, 환경정보, 입력 경로 계약, 원본 해시만 제출
2. 대회 시스템 내부 제출에 한해 원본을 zip에 포함
3. 운영진이 별도로 원본을 배치하고 참가자는 코드만 제출
4. 다른 지정 방식

또한 공식 공고에서 한글 파일명·경로 오류로 실행이 불가능하면 실격될 수 있다고 안내하므로, 원본 폴더명이 한글인 경우 권장 입력 배치 방식과 실행 기준 디렉터리도 알려주시면 감사하겠습니다.

답변은 실험·제출 규정 기록으로 보존하고 그대로 준수하겠습니다.

- 공식 사실: 위 ScienceWatch I-ORS 두 페이지는 CC BY 4.0, 기간, 변수, 시간 해상도와 버전을 명시한다.
