## 1. 답안 채점

| 문제 | 페이지 | 답안 열 | 알려진 행 수 |
|---|---|---|---:|
| P1 | https://oceanaidata.org/app/problems/5 | station,year,layer,time,label | 169011 |
| P2 | https://oceanaidata.org/app/problems/6 | station,layer,time,temp | 26061 |
| P3 | https://oceanaidata.org/app/problems/7 | case_id,station,lead_h,hs_pred | 1200 |

1. 정확한 후보의 실험 ID, 적격 학습 계보, 내부 비교, schema/keys/order/finite/hash, 저장 모델 재현 검사를 확인합니다.
2. 현재 사용자 승인 범위를 확인합니다. 이미 승인된 행동을 다시 묻지 않되, 최종 모델 잠금 승인은 답안 채점 승인과 구분합니다.
3. 로그인된 공지와 문제 화면에서 실제 마감·오늘 남은 횟수·중복 제출 여부를 확인합니다. 과거 숫자를 현재값으로 쓰지 않습니다.
4. 파일 선택 → 정확한 파일명 확인 → 제출하고 채점 한 번. 불확실한 응답에서는 재클릭보다 접수 내역 확인이 먼저입니다.
5. /app/submissions에서 접수 ID·문제·파일·상태·공식 지표를 확인하고 SHA와 KST 시각을 receipt에 기록합니다.

리더보드 점수는 해당 SHA의 공식 값이며 내부 RMSE/F1 또는 다른 replay 파일에 옮겨 붙이지 않습니다.
행 수는 배포 계약과 실제 sample keys로 다시 검증합니다. hidden truth는 열지 않습니다.

## 2. 최종 모델·재현 제출 — 별도 행동

최종 지정은 이후 답안 업로드를 막을 수 있습니다. 현재 모델로 채점할 일을 끝낸 뒤 잠금 효과까지 승인된 경우에만 진행합니다.

- 로컬 구조: 데이터 참조 / 학습 코드 / 학습 과정·로그 / 학습된 모델 / 추론 답안 / README·환경·제출 양식.
- 원본부터 모델과 답안을 재생성하는 경로와 네트워크 없는 6시간 제한을 검사합니다. 저장 모델 추론만 통과한 것은 전체 학습 재현 증거가 아닙니다.
- README에는 문제별 모델·학습/추론 명령·파일 선택·환경·소요시간·해시를 기재합니다. 합성-only 사전학습 예외 사용 시 버전·가중치 동봉/로컬로드·데이터 성격을 명시합니다.
- 소스 데이터의 재배포 권한 없이 ZIP에 넣지 않습니다. 외부자료/비밀정보/과거 부적격 계보도 제외합니다.
- 현재 UI의 파일 크기/첨부 제한을 보고 필요한 분할과 manifest를 검증합니다. 옛 24개 첨부 수를 새 모델에도 고정 적용하지 않습니다.
- 모델 최종 제출하기 → 제목/요약/재현 파일/저장소 URL 확인 → 잠금 경고 → 승인 범위 내 최종 클릭 한 번.
- 첨부 중 실패하면 기존 접수 레코드와 첨부 상태를 먼저 확인합니다. 중복 레코드를 자동 생성하지 않습니다.
