2. 작업 순서
━━━━━━━━━━━━━━━━━━━━

A. 06 대조
로컬 06_PRESENTATION_PLAN.md의 실제 12장과 보고서 2-1 검토표를 1:1로 맞춘 차이표를 만든다.
형식: [장 | 06 원안 제목·역할 | Claude 수정안 | 채택/수정/기각 | 이유]
재구성 오류(장 순서·역할이 다른 것)는 정정만 하고 비판으로 쓰지 않는다. 기각에는 근거 파일을 적는다.

B. 06 갱신
채택한 수정안을 06에 반영한다. 장마다 화면 제목, 핵심 그림, 각주, 발화 요약을 적는다.
발화는 보고서 4절 문장을 사용하되 슬라이드 본문에 대본을 넣지 않는다.
"12장·10분"은 공식 조건이 확인될 때까지 내부 가정으로 표기한다.

C. 수치 재대조
보고서 2·5절과 시안 HTML의 모든 수치를 아래 §3 표와 원본 receipt/result로 다시 대조한다.
불일치가 있으면 시안·보고서를 고치지 말고 [항목 | 보고서 값 | 원본 값 | 파일]로 보고한다.

D. 디자인 기준 확정
사용자가 달리 정하지 않으면 방향 A(밝은 기술 편집형)를 채택한다. HTML 시안의 규칙을 PPT 기준으로 옮긴다.
- 바탕 #F7F9FB, 본문 #0F2540, 보조 글자 #4A5D74, 선 #D5DEE6, 패널 #FFFFFF
- 강조 청록 막대 #0A9A92 / 청록 글자 #087C76, 악화 표시 #C4701F, 기준(비교 대상) 막대 #A7B4C2
- 글꼴: Pretendard 또는 맑은 고딕, 수치는 고정폭(D2Coding 등) 가능
- 16:9. 화면 폭 1280 기준 제목 약 40px, 본문 18~21px, 각주 19px. 강조는 제목 한 구절과 "이번에 바꾼 것" 한 요소에만
- 막대 축은 0에서 시작, 값·단위·비교 기준을 막대 옆에 직접 표기, 부호 있는 값은 0선 양방향

E. 편집 가능한 PPTX 12장 초안
텍스트·도형 단위로 만든다. 슬라이드 전체를 이미지로 넣지 않는다. 차트는 실제 값으로 네이티브 차트나 도형으로 그린다.
4·7·11장은 시안의 문구·배치를 그대로 옮긴다. 6장(P2 프로파일 개념도)·8장(P3 구조도)은 "개념 예시"를 표시한다.
P1 구성 요소별 점수 막대 등 없는 수치는 만들지 않는다.
결과: 파일 경로, bytes, SHA-256, 장별 한 줄 요약.

F. 부록
보고서 5절의 질문 6개를 부록 슬라이드로 만든다(본편에 넣지 않음). 답변은 확인/해석/미확인 구분을 유지한다.

G. 자체 검토
각 장에 대해 다음 7개를 점검해 표로 남긴다: 청중이 새로 이해하는 것 / 앞 장과의 연결 / 제목과 그림의 일치 / 근거보다 강한 표현 / 설명 없는 용어 / 중복 / 평가 항목 근거 누락.
