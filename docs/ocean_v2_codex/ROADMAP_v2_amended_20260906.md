## 2. 재생성 증거의 범위 (Codex 보고 반영)

- P1: 새 학습·추론은 되지만 과거 답안과 ≥110 라벨 상이 → **재생성된 답안이 기준**이며 과거 답안은 비교 기록으로만. 원인(비결정 학습·seed·스레드·bf16)을 분류해 기록.
