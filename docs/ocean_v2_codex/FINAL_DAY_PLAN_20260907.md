## 1. 원칙 (오늘 절대 어기지 않을 것)

1. 업로드하는 모든 후보는 **업로드 전에** SOURCE_ONLY(빈 모델→학습→답안)와 SAVED_MODELS(저장 모델→답안) 두 경로로 같은 SHA를 만드는 패키지가 있어야 한다. 패키지 없는 후보는 올리지 않는다.
2. 후보는 사전 등록(설정 파일 + 예상 비용 + 판정 규칙)한 뒤 실행한다. 공개 점수를 보고 계수를 바꾸지 않는다. 공개 점수는 **사전 등록된 후보들 사이의 선택**(공지가 허용한 참고 용도)에만 쓴다.
3. 문제별 최종 지정 = "패키지 재생성을 통과한 후보 중 공개 점수 최고". 차이가 P3 0.003m / P2 0.002℃ / P1 0.002 F1 이내면 **더 단순한(상수가 적은) 쪽**.
4. 슬롯 3은 각 문제 모두 **예비**로 남긴다(패키지 재생성 답안이 채점본과 SHA가 다를 때 그 재생성본을 올리는 용도). 예비를 후보에 쓰는 것은 15:00 이후 결정.
