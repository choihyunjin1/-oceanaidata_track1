# 전처리(이상값 제거) 정찰 결과 — 2026-09-06 (Claude, 읽기 전용 집계)

질문: "원본 데이터의 이상점을 제거·가공한 뒤 학습하면 성능이 오르지 않을까?"
결론: **세 문제 모두 "값 제거"는 손해이고, 가치 있는 전처리는 (P1) 물리 범위·동일값 하드 룰과 정상 수준 추정 잔차, (P3) 정보 없는 hmax 특징 제거와 결측 패턴 정합, (P2) 결측 패턴 정합뿐이다.** 근거 수치는 아래.

## P1 (train 776,706행 / test 169,011행)
| 항목 | 수치 | 함의 |
|---|---|---|
| 물리 범위 이탈(**고정 [0, 35]℃** 규칙) | train 라벨0 0행, 라벨1 805행; test 123행(전부 S-ORS, 최저 −20.66℃); 현재 챔피언 답안은 123행 중 103행 양성 → 규칙 적용 시 20행이 추가로 양성 처리됨 | **(09-07 정정)** 이 수치는 고정 [0,35]℃ 규칙의 결과이며, 학습 라벨 0 min/max(5.0017~30.8965℃) 규칙과 다르다. 후자는 test 653행을 바꾸고 그중 0~5℃ 구간 521행(G-ORS 3월·S-ORS 2~6월, \|Δ\| 중앙값 0.044℃)은 자연 저수온으로 보여 **대량 FP 위험**. 전자는 학습 라벨 0에 5℃ 미만 행이 없어 0~5℃ 구간의 FP 여부를 학습 자료로 검증할 수 없다. "FP 0 확실·공짜 규칙·TP 20행" 표현은 철회. 20행은 확인된 TP가 아니라 추가 양성 예측이다. **후보 아님** |
| 동일값 연속 run | train 라벨0 run 길이 ≥3: {3:2, 4:1}, ≥6: 0; test run ≥6: 27개(2,428행, 모두 ≥11행) | 하드 룰 `run≥6 → 1`은 FP 0. 현재 답안은 2,374/2,374 양성(이미 잡힘) |
| 자연 급변(라벨0 \|dT\|>2℃) | train 15,833행(2.13%), test 2,741행(1.62%); 5~10월 S-ORS 중층 집중, test는 5~6월 2,607행 | **삭제·가중 축소 금지**. test에서도 라벨 0으로 채점되는 핵심 hard negative |
| 수온-염분 동반 | \|dT\|>1 행에서 \|dS\| 중앙값: 자연 0.221(\|dS\|<0.02는 4.7%) vs 주입 0.017(51.3%); test 0.190(9.0%) | "psal이 조용한 temp 점프" 특징이 자연/주입을 강하게 분리. test 분포는 자연 다수 + 주입 소수와 정합 |
| 결측 | psal train 2.15% → test 0.47%; depth train 0.15% → test 9.68%(G-ORS 전결측) | depth 특징 제거(또는 G-ORS 마스킹) 필요, psal은 문제 없음 |
| 이벤트 경계 근처 라벨0 | ±3행 이내 1,836행 | 경계 모호성은 후처리 대상, 삭제 대상 아님 |
